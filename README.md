# RESCO Website

Modern marketing website for Renewable Energy System Co. LLC (RESCO), inspired by premium energy-sector design.

## Quick Start

Open `index.html` in your browser, or serve locally:

```bash
# Python
python3 -m http.server 8080

# Or with npx (if Node.js is installed)
npx serve .
```

Then visit `http://localhost:8080`

## Structure

- `index.html` — Full single-page site (Home, About, Services, Projects, Clients, Contact)
- `styles.css` — Design system and responsive styles
- `main.js` — Navigation, scroll animations, stat counters, contact form

## Sections

1. **Hero** — Fit for Purpose messaging with CTAs
2. **Services** — All 10 product/service categories from the original site
3. **About** — Company overview, vision, mission
4. **Stats** — Year established, projects, contractors, awards
5. **Projects** — Portfolio showcase
6. **Clients** — Client trust section
7. **Contact** — Form + Nairobi, Muscat, Goa offices

## Customization

- Replace client logo placeholders in the Clients section with actual client images
- Add real project photos to `.project-image` elements
- Connect the contact form to your backend or email service (Formspree, etc.)
